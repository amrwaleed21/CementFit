CementFit - تحديث الموقع
1) فك الضغط
2) على GitHub افتح الريبو CementFit > Add file > Upload files
3) اسحب كل اللي جوه: home.html و products.html و product.html و admin.html وفولدر assets
4) Commit changes (هيستبدل القديم، ومش بيمس vercel.json ولا dumbbellmodel.glb)
5) افتح admin > تبويب "الإحصائيات": لو ظهرت رسالة تجهيز، انسخ كود SQL وشغله مرة واحدة في Supabase > SQL Editor
